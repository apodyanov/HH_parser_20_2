# Парсер вакансий с HH.ru

Курсовой проект по работе с базами данных PostgreSQL и API HH.ru.

## Описание проекта

Проект позволяет:
- Получать данные о компаниях и вакансиях с сайта HH.ru через публичный API
- Сохранять полученные данные в PostgreSQL
- Анализировать данные через удобный консольный интерфейс

## Функциональность

1. **Список компаний и количество вакансий** - показывает все компании и сколько у каждой вакансий
2. **Список всех вакансий** - детальная информация по всем вакансиям
3. **Средняя зарплата** - расчет средней зарплаты по всем вакансиям
4. **Вакансии с зарплатой выше средней** - фильтрация высокооплачиваемых вакансий
5. **Поиск по ключевому слову** - поиск вакансий по названию

## Технологии

- Python 3.9+
- PostgreSQL
- Psycopg2
- Requests
